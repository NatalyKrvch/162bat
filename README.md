# Official Website of the 1st Battalion of the 119th Separate Territorial Defense Brigade

---

## Project Overview

This is the **official informational and recruitment website** of the **1st Battalion of the 119th Separate Territorial Defense Brigade**.

The website provides verified information about the battalion, its history, guarantees, available vacancies, and includes a recruitment form that sends applications directly to the battalion’s email via EmailJS.

---

## Tech Stack

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **React Hook Form**
- **EmailJS**
- **Husky + lint-staged**
- **ESLint + Prettier**
- **Vercel**

---

## Website Structure

- `/` — Landing page with general information and a recruitment form
- `/faq` — Frequently Asked Questions
- `/history` — Battalion history
- `/guarantees` — Benefits and guarantees for servicemen
- `/vacancies` — List of current vacancies
- `/privacy-policy` — Privacy policy

---

## Recruitment Form

The website includes a recruitment form that allows potential servicemen to submit an application.  
All form submissions are processed and sent to the battalion's email via **EmailJS**.

---

## SEO Features

- Custom **meta tags** for all main pages
- Implemented **robots.txt**
- Implemented **sitemap.xml**
- `<html lang="uk">` for proper indexing
- Local UAF Sans font with `font-display: swap`

## Development

### Installation
```bash
npm install
```
### Run development server
```bash
npm run dev
```
### Build for production
```bash
npm run build
```
### Start production server
```bash
npm start
```

## Deployment

The project is deployed on Vercel.
No additional deployment configuration is required.
